# AppleWin key remapping
# ======================
# You can also edit bindings in AppleWin: Configuration > Input > Key Remapping.
# Put this file next to AppleWin.exe. It is re-read automatically
# whenever you save it, so you can edit it while a game is running.
#
# Format:   <key you press> = <key the Apple II sees>
# Remove the '#' at the start of a line to turn that mapping on.
#
# Each key is only remapped once, so swaps work (A = D and D = A).
# Remapping only applies while the emulator is running, not in the debugger.
#
# Key names:
#   Letters/digits:  A..Z  0..9
#   Space Return Enter Esc Tab Backspace Delete Insert
#   Left Right Up Down Home End PageUp PageDown
#   Numpad0..Numpad9 NumpadMultiply NumpadAdd NumpadSubtract NumpadDecimal NumpadDivide
#   Minus Equals Comma Period Slash Semicolon Quote Backquote LBracket RBracket Backslash
#   LAlt RAlt   (= Open-Apple / Closed-Apple, also joystick buttons 0 / 1)
#   F1..F12     (careful: F1-F12 are also AppleWin's own shortcut keys)
#   Any single symbol, e.g.  ;  /  [
#   Raw Windows virtual-key code, e.g. 0x41
#
# Shift still works as normal: if Q = 5, then Shift+Q types %.
# Shift/Ctrl themselves can't be remapped.

# Examples:
# Q = 5
# Space = Return
# Up = I
# Down = K
# Left = J
# Right = L
